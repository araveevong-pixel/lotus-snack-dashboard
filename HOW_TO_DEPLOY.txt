==========================================
LOTUS Dashboard — How to deploy
==========================================

Just double-click "deploy.command" — this opens Terminal and runs the deploy script.

Or run from Terminal:
   cd ~/Desktop/lotus-snack-dashboard
   bash deploy.sh

What happens:
  1. Detects your gh CLI authenticated user
  2. Creates GitHub repo at <your-user>/lotus-snack-dashboard
  3. Pushes all files
  4. Enables GitHub Pages
  5. Triggers first TikTok scrape

After 1-2 minutes, dashboard is live at:
  https://<your-user>.github.io/lotus-snack-dashboard/

The dashboard auto-updates every 30 minutes via GitHub Actions.
