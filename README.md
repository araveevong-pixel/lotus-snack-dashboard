## Stack
- Static HTML + Chart.js
- yt-dlp scraper (runs every 30 min via GitHub Actions)
- Auto-deploy to GitHub Pages

## How it works
1. `scripts/tiktok_scraper.py` pulls metrics from TikTok video URLs using yt-dlp
2. `scripts/update_dashboard.py` injects scraped data into `index.html`
3. `.github/workflows/auto-update.yml` runs both on a 30-min cron
